MHA WEB POS v11 - FUTURISTIC UI
================================

This package continues from your previous MHA Web POS v10 and applies the new futuristic Aurora UI skin.
The business logic and existing POS workflows are retained.

HOW TO RUN ON WINDOWS
---------------------
1. Extract this ZIP to a normal folder, for example:
   D:\MHA-Web-POS-v11
2. Open Command Prompt (CMD).
3. Change to the extracted folder, for example:
   cd /d "D:\MHA-Web-POS-v11"
4. Install dependencies:
   npm install
5. Start the POS:
   npm run dev
6. Open the local address shown by Vite, normally:
   http://localhost:5173

If PowerShell shows "npm.ps1 cannot be loaded", use CMD instead.
